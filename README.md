# MAVA tea — демоверсия

Готовый статический сайт: сначала открывается «О нас», затем меню, корзина и демоадминка. Регистрация и сервер не нужны. Все фотографии входят в архив.

## Посмотреть сразу

Распакуйте весь архив в одну папку и откройте `index.html` двойным кликом. Меню находится в `menu.html`, демоадминка — в `admin.html`. Не открывайте HTML прямо внутри ZIP.

При таком запуске стакан показан изображением. На веб-хостинге доступна исходная анимация. Если браузер запрещает хранение данных для локальных файлов, редактирование в демоадминке лучше проверять по опубликованной ссылке.

## Опубликовать через GitHub Pages

1. Создайте отдельный публичный репозиторий для демо.
2. Загрузите **содержимое** этой папки в корень репозитория. В корне должны быть `index.html`, `menu.html`, `assets/` и остальные файлы. Сам ZIP загружать вместо файлов не нужно.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.
5. Дождитесь публикации. GitHub покажет адрес сайта на той же странице. Посетителям не нужен аккаунт GitHub или Netlify.

Поддерживаются и адрес вида `https://имя.github.io/репозиторий/`, и отдельный домен. Менять название репозитория в коде не требуется. Команда сборки не нужна.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Другой статический хостинг

Размещайте корень этой папки. Для Netlify уже указан `publish = "."` в `netlify.toml`; команду сборки оставьте пустой. Доступ для посетителей настраивается в самом хостинге — файл сайта не может отменить требование входа, установленное хостингом.

## Что делает демо

- Содержит 51 позицию меню и 3 точки MAVA.
- Открывает демоадминку без пароля. Это режим показа, не настоящая защита администратора.
- Изменения сохраняются только в браузере посетителя и не меняют данные у других людей. Кнопка «Сбросить демо» возвращает исходные данные.
- Заказ оформляется во внешнем ZaZa или по телефону 5445. Корзина не передаётся в ZaZa автоматически.
- Не принимает оплату и не отправляет заказы на сервер.

Исходный каталог находится в `demo-data.js` (используется сайтом) и `demo-menu.json` (копия для удобства). Это отдельное демонстрационное издание проекта; для рабочего магазина с общим редактированием нужен серверный вариант.
